<theme_direction>
## Theme direction fed inline to every impeccable call (D-11, D-12, D-15)

Retro, PostHog-spirited, dark, and legible from the back of a room on a projector. A dense operator console a developer would trust: not neo-brutalist parody, not terminal cosplay.

Palette, as CSS custom properties in `app/globals.css` only. These are the D-11 starting values; impeccable may propose stronger ones as long as they stay dark, retro and projector-legible, and as long as they remain token values in this one file.

| Role | Value |
|---|---|
| page ground (background) | `#0B0B0C` |
| panel surface (card) | `#141416` |
| raised surface / row hover (elevated, and shadcn's muted and popover and accent) | `#1C1C20` |
| hard structural border (border, input) | `#2E2E33` |
| primary text (foreground, card-foreground, popover-foreground, accent-foreground) | `#EDEDEF` |
| secondary text and micro-labels (muted-foreground) | `#8A8A93` |
| amber: pending, focus ring (primary, ring) | `#F2A93B` |
| cyan: already scheduled (secondary) | `#4EC9E0` |
| green: confirmed and acted (success) | `#46C07A` |
| red: error states (destructive) | `#E5544B` |
| dark text on every filled chip (primary-foreground, secondary-foreground, success-foreground) | `#0B0B0C` |

Devices, applied consistently: 1 to 2 pixel hard borders; 4px 4px 0 offset shadows with no blur; 2 to 4 pixel radii; monospace with tabular numerals for data, timestamps, confidence, chips and table columns; proportional sans for prose; uppercase letter-spaced micro-labels; status encoded in form (chip plus symbol) as well as colour. No gradients, no glass, no soft elevation, no animation.

Accessibility facts already computed against these values (WCAG relative luminance, research contrast findings): amber on the ground 9.85:1, cyan 10.08:1, success 8.51:1, destructive 5.34:1, foreground on ground 16.83:1, muted-foreground on ground 5.75:1 — all pass. White text on a filled amber chip is 1.71:1 and on filled cyan 1.67:1 — both fail badly, so every filled chip uses the dark text value. The border token against the ground is 1.46:1, acceptable for a decorative divider and a candidate to lighten toward a slightly brighter grey if a stronger palette is proposed.
</theme_direction>
