# Phase 11 Plan 01: Screen-record one clean run (DMO-03)

## Phase Goal

**As a** solo presenter at judging, **I want to** have one clean screen recording of the full demo path, **so that** a venue-wifi failure on stage still leaves a working demo to show.

Framed from the ROADMAP Phase 11 Goal line ("A clean run is recorded as the wifi fallback, and the README is complete"), which is not itself in user-story form. The framing adds no scope.

## Acceptance Criteria

- [ ] ROADMAP SC1 / D-06: played back once, the take shows the entire demo path with no dead air longer than a few seconds and no narration filling a gap
- [ ] No secret and no notification toast visible anywhere in the take
- [ ] Take plus backup copy exist outside the repo; nothing video-shaped is untracked inside it (D-01)
- [ ] Phase 10 processes shut down only after playback confirmed the take (D-08)

<objective>
Record one clean run of the rehearsed demo path on main with Windows 11 Snipping Tool, verify it by playback, back it up outside the repo, then stop the demo processes.

Purpose: the recording is the on-stage mitigation for venue wifi, not a code fix (D-07). Per D-03 this is plan 11-01 of two; it runs in Wave 1 beside 11-02 because it modifies no repo file.
Output: one confirmed take in %USERPROFILE%\Videos\Screen Recordings\ plus a copy in %USERPROFILE%\Desktop\ai-secretary-demo-fallback\. No repo changes.
</objective>
